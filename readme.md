El sitio ahora es una aplicación modular construida con React + Vite (en JavaScript). Todas las funcionalidades interactivas se desarrollaron de forma independiente como componentes reutilizables en la carpeta `src/components/`:

1. `GaleriaImagenes.jsx` - Galería de imágenes interactiva con visor (modal) en tamaño grande.
2. `CalculadoraCotizacion.jsx` - Presupuesto con cálculo del precio total en tiempo real.
3. `FiltroActividades.jsx` - Buscador que filtra las actividades en tiempo real.
4. `FormularioReservacion.jsx` - Formulario de reservación con validación y mensaje de confirmación.
5. `Testimonios.jsx` - Sección de opiniones de visitantes que alterna testimonios aleatorios.

También se reutilizó el diseño del sitio original (`estilos/estilos.css`) y las imágenes (`imagenes/`).

Comandos útiles:

- `npm install` - Instala las dependencias.
- `npm run dev` - Levanta el servidor de desarrollo.
- `npm run build` - Genera la versión de producción en `dist/`.
